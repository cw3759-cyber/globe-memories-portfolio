# 90 秒演示路线

先启动 README 中的 `demo.app:app`，打开根地址。示例账号 `demo` / `demo2026` 会自动填入。另一个示例账号是 `case` / `demo2026`，可用于展示作者权限。

## 0–20 秒：说清需求

“这是为情侣保存照片和回忆设计的共同地球。我负责全程产品设计，用 AI coding 实现。当前看到的都是虚构模板。” 展示地球和左侧时间线。

## 20–45 秒：展示回看

选择时间线「第一次遇见」，查看地点、日期、作者和图片；关闭详情并适当缩小，点开该区域气泡，展示四段回忆分别展开。说明聚合用于解决遮挡，每段经历仍独立保存。

## 45–65 秒：展示记录

点击「增加地点」，展示标题、日期、地点、描述和照片。联网时搜索并选择明确地点；网络不可用时仅展示表单，不声称地名录入可离线完成。

## 65–90 秒：展示共同记录

打开某段回忆，选择「就这里留言」，展示关联标签与既有虚构对话。模板可写，但多人共用；仅用示例文本。原产品邀请码注册能力由源码支撑，模板关闭注册，不能在这里演示真实加入。
