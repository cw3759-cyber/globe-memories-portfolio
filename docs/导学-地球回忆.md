# 导学｜地球回忆

## 1. 前置知识

- **产品闭环（高频）：** 记录、找回、互动，位置在 `docs/product-case.md`。
- **信息结构（高频）：** 一段回忆关联多个照片，位置在 `app/db.py`。
- **身份与归属（高频）：** 登录与作者权限是两层检查，位置在 `app/auth.py` 和 `app/main.py`。
- **空间聚合（中频）：** 距离规则与连通分组，位置在 `static/app.js`。
- **AI 边界（高频）：** AI coding 与产品内模型能力的区别，位置在 `docs/ai-scope.md`。

## 2. 重点亮点与学习顺序

1. 先理解用户任务，再看功能：读 `docs/product-case.md`，解释为什么需要地点和时间两种入口。
2. 再看回看体验：读 `static/app.js` 的聚合、展开、选择与时间线部分，理解信息密度与查找成本的取舍。
3. 看保存链路：读 `app/main.py`、`app/media.py`、`app/db.py`，说明保存成功究竟意味着什么。
4. 看模板隔离：读 `demo/app.py`、`app/globe_ctx.py`、`app/demoseed.py`，解释展示与私人内容的边界。
5. 最后看验证：读 `docs/evaluation.md` 和 `docs/verification.md`，区分功能检查与产品价值证明。

- [ ] 能画出记录到留言的完整用户流程。
- [ ] 能说明本人负责设计、AI coding 辅助实现的职责边界。

- [ ] 能说明图片压缩、地名歧义和搜索失败对体验的影响。

## 4. 推荐阅读

- 10 分钟：`README.md`、`docs/product-case.md`。读完能讲清用户、问题和价值假设。
- 20 分钟：`static/app.js`。按新增按钮 → 搜索 → 保存 → 重新加载 → 详情的顺序阅读；读完能说明操作后界面如何变化。
- 20 分钟：`app/main.py`、`app/media.py`、`app/db.py`。读完能区分元数据、图片文件和会话。
- 15 分钟：`demo/app.py`、`app/globe_ctx.py`、`app/demoseed.py`。读完能解释公开模板为何不加载私人服务。
- 15 分钟：`app/cloudbackup.py`、`docs/decisions.md`。读完能解释备份失败时为何拒绝空库启动；没有恢复演练，不代表已保证数据可靠性。

## 5. 自学提醒

若某文件或原理看不懂，请继续追问 AI；本技能负责给学习路径与题目，不提供逐行讲解。不要背诵未经理解的源码术语来代替自己的产品判断。

## 6. 项目技术定位

**产品 / Web 交叉原型。** 有真实前后端和交互实现，使用 AI coding 辅助开发，运行时不包含模型能力。

## 7. 核心原理

- 回忆重叠 → 空间聚合再展开 → `static/app.js` 保留每条记录的独立详情。
- 文本地点与坐标不符 → 查询候选和纠偏规则 → `app/main.py`，需关注误纠偏。
- 图片过大 → 压缩与缩略图 → `app/media.py`，不等于无损原图存储。
- 共享浏览但防止互删 → 身份认证后再查作者 → `app/main.py`。
- 对外展示但不能带私人内容 → 独立种子、上下文、公开入口 → `demo/app.py` 等。

## 8. 关键设计决策

备选包括直接点击创建、平面列表、固定阈值或随缩放聚合、实时通信或轮询。当前选择及其代码证据见 `docs/decisions.md`；替代方案是复盘分析，不能说成当时已经做过完整实验。

## 9. 量化与验证

建议先测记录完成率与指定回忆找回成功率，再观察双方是否持续贡献。真实用户结果均待测；本次本地功能验证见 `docs/verification.md`。恢复可靠性、并发、移动触控和无障碍另行验证。
