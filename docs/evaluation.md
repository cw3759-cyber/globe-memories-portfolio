# 指标与验证计划

## 已知证据和未知结果

目前可用证据是源代码、历史提交、模板数据和本次本地验证。没有真实用户漏斗、留存、满意度或 A/B 实验数据。Demo 的 7 段回忆不计入用户量、内容增长或产品效果。

## 核心目标与口径（建议，尚未埋点）

**核心观察：双方共同记录的地球比例。** 在完成第二位成员加入的地球中，观察加入后 14 天内双方是否各新增至少一段回忆。分子为满足条件的地球数；分母为已完整经过观察窗口的已配对地球数。只计真实、自愿参与的试用，排除 Demo、内部测试和导入内容。当前数据库没有多地球标识，需未来实现或在研究中手工按组统计。

配套指标：

- 首次记录完成率：成功保存首条有效回忆的参与者 / 开始创建任务的参与者；记录失败原因，不把退出一律理解为无需求。
- 找回成功率：无需提示找到指定回忆的任务数 / 所有指定回忆查找任务数；另记录耗时分布及错选次数。
- 协作激活率：邀请后 7 天内另一位成员加入并完成首次有效贡献的地球数 / 发起邀请且观察满 7 天的地球数。
- 持续使用：第 2 周至少发生一次回看或贡献的试用地球比例，须报告观察窗口和样本数。小样本只作方向判断。
- 可靠性护栏：记录保存失败率、照片加载失败率、错位报告；私人模式另测恢复完整性。

## 建议观察事件（未实现）

创建开始、创建成功/失败、详情打开、聚合展开、邀请创建/使用、留言提交、会话开始。记录时间、匿名参与者和任务编号即可；不采集照片、留言正文或精确坐标作为分析数据。字段、去重、撤回及保留期应在研究前定义。

## 第一轮任务测试（待执行）

建议 3–5 对情侣，自愿使用虚构材料或自选非敏感内容。先询问当前记录方法，再按以下任务观察；不要先教会全部操作。

1. 新建一段带标题、日期和照片的回忆；记录完成与失败节点。
2. 从同一城市的四段回忆中找到指定日期的一段；观察是否理解聚合与展开。
3. 在该回忆下留言，切换另一账号找到回应和关联地点。
4. 解释重启后 Demo 会如何变化，以检查是否理解模板边界。

对比地球与时间线找回时，交叉安排任务顺序，避免学习效应。先形成基线再设耗时与成功率目标；不把任意百分比当成已承诺 KPI。

## 决策规则

如果首次记录卡在地点搜索，先解决错误提示和候选歧义；若回看卡在聚合，先调整阈值或增加列表入口；只有发现重复填写是主要负担，才进入 AI 预填实验。每轮记录样本数、失败样例和改动范围。
