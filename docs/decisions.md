# 产品决策与取舍

以下“演进”有提交记录与现有代码支持；“产品解释”是本次复盘分析，不代表当时已有正式实验结论。历史提交来自源仓库，本作品集副本不携带原 Git 历史。

## 1. 将探索和创建分开

- 演进：`8b93250` 将点地球改为打开已有回忆，新增改到底部按钮。
- 当前行为：点击无回忆区域提示使用「增加地点」，不直接打开创建表单。
- 产品解释：先让浏览者理解“这里有什么”，把写入作为显式动作。
- 代价：地图即点即记的快捷性下降，创建入口的发现性需要测试。
- 验证：记录无意打开创建表单次数、首次找到创建入口时间和首次记录完成率。暂无对比结果。

## 2. 从覆盖气泡到展开每一段回忆

- 演进：`81886dc` 多段回忆列表 → `023c85d` 拍立得展开 → `0b46b51` 修复遮挡 → `9816a7b` 邻近地点聚合。
- 当前行为：15 km 内的邻接点以连通分组聚合，按日期组织，展开卡片逐段访问。
- 产品解释：聚合减少遮挡，展开保留事件粒度；不把多段回忆合并成一条记录。
- 代价：连通关系有传递性，一组最远两点可能超过 15 km；固定阈值未适配城乡密度与缩放等级。全量两两比较也不适合大规模记录。
- 验证：在同城密集、跨城稀疏及链式邻接样例中寻找指定回忆；观察遗漏、错选和查找时间。

## 3. 地点错误优先于装饰性地图细节

- 演进：`e1578d2` 地名坐标纠偏，`6edf993` 支持备份清单修正错位；`74b948a`、`fe48ffa` 收敛地图标签。
- 当前行为：中文搜索包含中国范围候选；名称与坐标明显不符时可能采用搜索结果。地图标签按指针位置和缩放层级展示。
- 代价：同名地点与海外中文地名仍有歧义；80 km 纠偏规则不能代表准确率。前端非空地点在搜索失败时不能保存，原 README 的完整离线描述不成立。
- 验证：用已知坐标的中英文同名地点做测试，衡量候选选对比例与误纠偏次数。

## 4. 简单协作优先，保留归属边界

- 现有实现：邀请码加入同一地球；成员共享查看，地点与照片删除由作者权限约束；留言每 4 秒轮询。
- 产品解释：符合少量成员异步回访的场景，减少即时通信系统复杂度。
- 代价：轮询存在等待和重复请求，不等同即时消息；成员模型不能直接扩展成多情侣隔离平台。
- 验证：两账号分别操作，检查未读、关联跳转和越权请求；长期并发尚未验证。

## 5. 数据可靠性影响用户对回忆的信任

- 演进：`a2105e3` 阻止瘦数据覆盖更丰富备份；`a2936eb` 补回启动恢复逻辑；`ae612c1`、`36d9c92` 处理手机会话及退出后登录问题。
- 当前行为：私人服务配置备份却恢复失败时拒绝空库启动；使用记录数量判断潜在覆盖风险。
- 代价：可用性让位于数据保护；按数量判断可能阻碍合法删除同步，不等于完整版本冲突处理。备份仍依赖外部服务与配置。
- 边界：这些是原私人产品能力，本次公开入口不启动私人恢复或备份。未连接真实备份做测试，不能声称零丢失。

## 6. 可展示的模板与私人内容分开

- 演进：`9b15ad6` 独立虚构 Demo，`7607fbf` 修正其静态资源路径。
- 本次新增：公开入口只开放 `/demo`，默认启动与部署配置均使用该入口；不启动私人生命周期。
- 代价：所有访客共享示例账号与状态，不能用它收集真实回忆；重启会复原，尚无逐访客隔离和定时清理。
- 验证：检查根路径跳转、私人 API 不可达、Demo 图片需登录、示例写入及重启复原。
